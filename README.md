# Нейросетевая адаптация сетки бака трансформатора в ANSYS

Проект для конкурса «Система»: тема холдинга ЭРСО
**«Новейшие методы расчета баков на механическую прочность»**.
Цель — уменьшить ресурсы прочностного расчёта при контролируемой точности
инженерных величин с помощью адаптации конечно-элементной сетки.

Ближайший практический рубеж: **Python запускает два расчёта одной модели
ANSYS с разной сеткой и сохраняет сравнение**. Сначала нужно найти прежнее
подключение VS Code/Python на Windows и зафиксировать механическую постановку.
Путь скрипта, API и порт пока не установлены. Два расчёта — проверка автоматизации,
ещё не доказательство выигрыша нейросетевой адаптации.

## Что сохранено и проверено

- Исторические пять этапов ASMR++: CSV, графики и исследовательские скрипты.
- `experiments/asmrpp/reproduce/`: снимок 209 upstream-файлов, локальный patch,
  разрешённый config, финальный и ранний checkpoints, нормализаторы, архитектура,
  метаданные окружения, MIT-лицензия и SHA-256 manifest.
- `experiments/asmrpp/runs/recovered_20261115_seed123/`: сохранённое воспроизведение
  одной Poisson-задачи (case 0) и отчёты двух независимых процессов.
- При подготовке Windows-передачи повторно проверена целостность 17 артефактов,
  209 файлов снимка и согласованность сохранённой траектории. Новый inference
  и обучение не запускались.

Из корня репозитория, без установки научных зависимостей:

```bash
python3 -B experiments/asmrpp/reproduce/reproduce.py --verify-only
```

На Windows с установленным Python Launcher:

```powershell
py -3 -B experiments/asmrpp/reproduce/reproduce.py --verify-only
```

Этот режим проверяет комплект, но не запускает модель или ANSYS.
`.gitattributes` сохраняет исходные байты экспериментальных файлов при checkout.

**Граница результата:** Poisson-политика пока не проверена на упругости и ANSYS.
Старый пилот (7/10 побед над бюджетным ZZ) не доказывает преимущества при равных
DoF или ускорения. Чистое окружение и нативный Windows-inference не проверены;
в сохранённых метаданных NumPy есть расхождение, разобранное в отчёте.
