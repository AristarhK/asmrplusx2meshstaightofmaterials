# Приоритет проекта: ASMR++ для прочностного расчёта в ANSYS

## Исходная цель пользователя

Разработать применение ASMR++ для оптимизации конечно-элементной сетки
прочностного расчёта в ANSYS и представить результат на конкурс «Система»
по направлению холдинга ЭРСО. Прикладной объект — бак силового трансформатора.
Пользователь сообщил, что ранее на Windows было настроено взаимодействие
VS Code/Python с ANSYS; конкретные файлы этой интеграции ещё не восстановлены.

Восстановление сохранённой Poisson-модели ASMR++ — техническая подготовка
к этой задаче. Основной критерий готовности проекта — работающий цикл
адаптации и подтверждённые измерения для задачи механики в ANSYS.

## Что должен делать прототип

1. Выполнить исходный прочностной расчёт фиксированной модели в ANSYS.
2. Экспортировать сетку, необходимые поля решения, материалы и граничные метки.
3. Выдать рекомендации локального сгущения с помощью адаптированной политики
   ASMR++; преобразовать их в поддерживаемые ANSYS средства управления сеткой.
4. Перестроить сетку с сохранением постановки, повторно решить задачу.
5. Повторять цикл по заранее заданному критерию и сохранять результаты.
6. Сравнить с исходной сеткой, равномерным сгущением и выбранным классическим
   адаптивным методом на одной геометрии и при одинаковых инженерных критериях.

Проверяемая гипотеза: нейросетевая адаптация может уменьшить ресурсы,
необходимые для достижения заданной точности инженерных величин.
Улучшение должно быть измерено; сохранённые Poisson-результаты его для ANSYS
пока не подтверждают.

Основные измерения: число элементов и DoF, полное время цикла, перемещения,
выбранные напряжения/реакции относительно проверенного reference, качество сетки.
Определение ошибки и критерии завершения фиксируются до сравнения.

## Текущая готовность и следующий шаг

| Часть | Состояние |
| --- | --- |
| Исторические эксперименты ASMR++ | Архивированы и проверены по CSV. |
| Источники, конфигурация и checkpoint | Восстановлены; см. ASMR_REPRODUCIBILITY.md. |
| Загрузка и inference сохранённой модели | Одна Poisson-траектория воспроизведена в двух процессах. |
| Связь Python ↔ ANSYS | Ранее создана пользователем на Windows; файлы требуют восстановления. |
| Расчётная модель бака и условия | В текущем рабочем комплекте ещё не определены. |
| Политика для упругости и ANSYS | Требует отдельной реализации и проверки. |
| Количественный результат для конкурсной задачи | Предстоит получить на механической постановке. |

Ближайшая разработка: восстановить прежний Windows-проект подключения к ANSYS,
зафиксировать первую механическую постановку и автоматизировать два её расчёта
с разной сеткой, экспортом и сравнением результатов. Порядок передачи и критерии
этого рубежа: [WINDOWS_HANDOFF.md](WINDOWS_HANDOFF.md). После проверки цикла и
отдельной проверки переноса на упругость подключить нейросетевую стратегию
и провести сопоставимые эксперименты.

Точные геометрия, материалы, нагрузки, закрепления, типы элементов, версия
ANSYS и интерфейс автоматизации берутся из реального проекта пользователя;
предполагаемые значения не выдаются за исходное ТЗ.
