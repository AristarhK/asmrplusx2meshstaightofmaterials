# Протокол выполняемого полосового сравнения P1

Исходный HEAD `4582fefd4e66804e866d7ae9432472588d344f6e`.
Параметры [protocol.json](../experiments/ansys_panel/strip_adaptivity/protocol.json)
сохранены до первого solve новой серии. Постановка и SHELL181 прежние.
EREFINE и исправление его переходных ячеек в этой работе не используются.

Общая начальная сетка: 20×12 интервалов, h=50 mm. Для каждого отмеченного
элемента выбирается более длинный его исходный интервал, при равенстве — X.
Добавляется середина выбранного интервала, линия проходит через всю панель.
Совпадающие запросы объединяются. Это **полосовое сгущение**, не произвольное
локальное разбиение. Дополнительный closure делит самый длинный интервал,
нарушающий глобальное отношение сторон≤4; равенства — X, затем меньший индекс.
Все дополнительные линии включаются в число ячеек, DoF и время.

Маркировка Дёрфлера θ=0.5: минимальный префикс по убыванию η_K²,
равенства разрешаются ID. Reference не участвует в наблюдениях, индикаторе
или маркировке. Предложение со всеми линиями проверяется целиком: при прогнозе
6(nx−1)(ny−1)>5382 оно отклоняется до solve. θ и маркировка не меняются.
Разрешены начальный solve, до трёх адаптивных solve и отдельный uniform h=25.

Индикатор следует N/M/Q-метрике [плана](ANSYS_PANEL_ADAPTIVITY_PLAN.md):
несглаженные native центроидные SMISC → подтверждённый элементный базис →
поворот в XY → площадной МНК линейных полиномов в узловых патчах → Q4 recovery.
Патч расширяется до ранга 3 и condition≤1e8, без скрытого константного fallback.
Вклад мембраны, изгиба и сдвига интегрируется отдельно с A⁻¹/D⁻¹/S⁻¹.
Порядки 2×2/3×3 сравниваются при допуске 0.1%; при необходимости 5×5, иначе отказ.
Поперечная жёсткость S проверяется по native секции/результантам и документации
однородного изотропного слоя; неизвестная жёсткость не подменяется молча.

Прежние геометрические/native shape-проверки обязательны до solve.
После solve проверяются Number of equations против прогноза, завершение
подшага TIME=1, сила, момент и линейная энергия. Центральный UZ берётся в
физической точке (500,300), шесть VM — интерполяция тензора и прежняя квадратура
по тем же кругам R=8 mm. Основные ошибки≤1%/5%, строгие≤0.2%/1% выводятся
независимо и не являются критериями стабилизации reference.

Общий начальный расчёт фактически выполняется один раз. Его полный измеренный
workflow, включая одинаковую диагностику индикатора/графа, относится к обоим
методам при сравнении самостоятельных цепочек. Затраты фактического выполнения
показываются отдельно, без двойного сложения общего старта. Uniform также
проходит тот же экспорт/диагностику на h=25; адаптивный метод дополнительно
оплачивает маркировку, перестроения, closure и отвергнутые предложения.
Время запуска и закрытия общей сессии учитывается одинаково для обоих.
Отдельно сохраняются времена стадий и сквозное wall time; разработка кода
не включается в измеренный цикл. Старые времена solve не используются.

Интерфейс selector(observation)→scores_per_element пока классический:
возвращает η_K². Наблюдение содержит граф элементов по общим рёбрам,
геометрию и физически нормированные N/M/Q/вклады индикатора. Нормирование
не использует reference, обученную статистику или Poisson-policy.
Обучение и нейросетевой inference не выполняются.
