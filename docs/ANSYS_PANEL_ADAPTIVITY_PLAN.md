# Следующий эксперимент: классическая адаптация P1 linear

Статус: **план, не выполненный эксперимент**. Подготовлен после локального
коммита аудита `ee7eab622326c7c7732c27d435d29c5bdaea9c33` в ветке
`windows/ansys-bootstrap`. Новых solve, обучения ASMR++, установки пакетов
и исправления RST-читателя при подготовке плана не выполнялось.

## Цель и рекомендуемый вариант

Проверить, достигает ли классическое локальное уточнение той же точности
контрольных величин с меньшим фактическим числом активных DoF и меньшим
накопленным временем, чем равномерное уточнение.

Рекомендация для первого baseline: **восстановление обобщённых усилий оболочки
в энергетической метрике → маркировка Дёрфлера → native EREFINE с сохранением
четырёхугольников**, за обязательными проверками совместимости и сетки.
Это использует текущий native MAPDL/PyMAPDL и механику мембраны/изгиба/сдвига.
Скалярный индикатор градиента Poisson и сохранённая нейросетевая политика
не переносятся в этот эксперимент.

Это recovery-индикатор, не гарантированная верхняя граница ошибки и не
непосредственная оценка ошибки каждого функционала. Нативное локальное
уточнение документировано, но его пригодность для нашей direct-N/E сетки
SHELL181 ещё не проверена. До успешных приёмочных этапов ниже весь локальный
цикл считается **требующим реализации и валидации**.

## Неизменная механическая задача

Исходная спецификация: [ANSYS_PANEL_SPEC.md](ANSYS_PANEL_SPEC.md),
конфигурация: [panel.json](../experiments/ansys_panel/panel.json).

- Полная панель 1000×600 mm, срединная поверхность z=0, толщина 8 mm.
- Линейно-упругий изотропный S235JR: E=210000 MPa, ν=0.30.
- Давление 0.005 N/mm² в +Z, результирующая +3000 N.
- P1: UX, UY, UZ, ROTX, ROTY, ROTZ равны нулю на всех четырёх кромках.
- Линейная статика, NLGEOM,OFF, без собственного веса/температуры/контактов.
- SHELL181, KEYOPT(1)=0, (3)=2, (8)=2; ETCONTROL,OFF;
  пять точек по толщине, SECOFFSET,MID; те же настройки решателя и nproc=2/-smp.
- Изменяется только сетка. Одни и те же правила ориентации, наложения нагрузки,
  выбора контура и экспорта действуют для обоих сравниваемых методов.

## Reference и целевые величины

Источник: сохранённый **P1 linear h=3.125 mm**, 61440 элементов,
61953 узла, 365574 активных DoF, из
[20261116_panel03](../experiments/ansys_panel/runs/20261116_panel03/).
Основание приёмки: два последовательных перехода по исходным контрольным
критериям, подтверждённые [аудитом](ANSYS_PANEL_AUDIT_20261116.md).
Это численный компаратор с ограниченной точностью, не точное решение.

| Цель | Значение reference |
|---|---:|
| Центральный UZ, mm | 0.15551121657326225 |
| Средний VM C, TOP, MPa | 5.689230832520771 |
| Средний VM C, BOTTOM, MPa | 5.689230832520771 |
| Средний VM Y, TOP, MPa | 6.327003107621079 |
| Средний VM Y, BOTTOM, MPa | 6.327003107621079 |
| Средний VM X, TOP, MPa | 4.0723451948659335 |
| Средний VM X, BOTTOM, MPa | 4.0723451948659335 |

Круги неизменны: C=(500,300), Y=(500,48), X=(48,300) mm, R=8 mm.
TOP/BOTTOM учитываются отдельно даже при совпадении линейных VM.
Сохраняется определение среднего: интерполяция глобального тензора в
физических точках → VM в точках → интеграл по кругу / его площадь.
Для новой неструктурированной Q4 сетки нужны поиск содержащего элемента
и обращение изопараметрического отображения; старый structured-grid
интерполятор для этого **не готов**. Квадратура должна иметь собственную
проверку точности и работать на той же физической области.
Центральный прогиб всегда относится к физической точке (500,300): если узла
там нет, использовать Q4-интерполяцию UZ внутри найденного элемента, а не
ближайший узел. Проверить восстановление узлового значения на исходной сетке.

Предварительно фиксируем ошибки сравнения:

\[
e_w=\frac{|w_h-w_r|}{|w_r|},\qquad
e_{s,j}=\frac{|\overline{\sigma}_{VM,h}^{s,j}-
\overline{\sigma}_{VM,r}^{s,j}|}{|\overline{\sigma}_{VM,r}^{s,j}|},
\quad s\in\{TOP,BOTTOM\},\ j\in\{C,Y,X\}.
\]

Фиксируются **две отдельные цели относительно сохранённого reference**:

| Цель сравнения | Центральный прогиб | Каждый из шести средних VM |
|---|---:|---:|
| Основная | e_w≤0.01, то есть 1% | все e_s,j≤0.05, то есть 5% |
| Дополнительная строгая | e_w≤0.002, то есть 0.2% | все e_s,j≤0.01, то есть 1% |

Выводить семь отдельных ошибок и флагов для каждого набора допусков,
`primary_goal_met` и `strict_goal_met` отдельно, а также фактические DoF и
накопленное время первого достижения **каждой** цели. Для непроверенной цели
использовать «не оценена», для проверенной, но недостигнутой — «не достигнута».
Сводные показатели: max(e_w/0.01,max(e_s,j/0.05)) для основной и
max(e_w/0.002,max(e_s,j/0.01)) для строгой цели. Основная цель задаёт первичный
результат сравнения; дополнительное продолжение до строгой цели ограничено
тем же заранее объявленным бюджетом и учитывается отдельно для обоих методов.

Эти ошибки сравнивают текущую сетку с **фиксированным** reference. Они не
являются критериями стабилизации самого reference: при его прежней приёмке
сравнивались **две соседние сетки** на двух последовательных переходах
(прогибы 0.2%, SENE 0.5%, площадочные VM 1%). Совпадение чисел строгой цели
с частью прежних допусков не делает определения ошибки одинаковыми.
Ни один из двух наборов не является доказательством абсолютной точности.
Не выбирать лучшие области или пороги после получения адаптивных результатов.

Глобальный максимум VM — **только диагностика**. Его последние изменения
в P1 составили 3.373% и 1.693%; reference для него не принят. SENE, максимальный
|UZ|, внутренний максимум, компоненты напряжений и реакции сохраняются как
дополнительные проверки, но не подменяют семь основных целей.

Равномерная сетка h=3.125 совпадает с самим компаратором: её нулевая разность
по определению не доказывает бесконечную точность или преимущество метода.
Чувствительность выводов проверять также относительно сохранённого h=6.25;
не обещать точность существенно ниже различия последних reference-уровней.
Непройденное прямое RST-чтение остаётся ограничением происхождения данных;
его статус не меняется этим планом.

## Математически определённый индикатор для оболочки

Для плоской однородной симметричной секции введём обобщённые усилия:

\[
N=(N_{xx},N_{yy},N_{xy})^T,\quad
M=(M_{xx},M_{yy},M_{xy})^T,\quad Q=(Q_x,Q_y)^T.
\]

N и Q имеют единицы N/mm, M — N·mm/mm=N.
Используются инженерные деформации (ε_xx, ε_yy, γ_xy),
кривизны (κ_xx, κ_yy, 2κ_xy) и поперечные сдвиги.
Так фиксируется коэффициент при кручении; смешивать тензорную и инженерную
конвенции без преобразования нельзя.

\[
C_p=\frac{E}{1-\nu^2}
\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&(1-\nu)/2\end{bmatrix},
\quad A=tC_p,\quad D=\frac{t^3}{12}C_p,\quad
S=k_sGtI_2,\quad G=\frac{E}{2(1+\nu)}.
\]

S должна соответствовать фактической поперечной жёсткости секции SHELL181.
Для одного изотропного слоя номинальный k_s=5/6; перед применением проверить
его согласованность с настройками секции и энергетическими контрольными
тестами. Не подменять неизвестную фактическую жёсткость молчаливым допущением.
Мембранно-изгибная связь B=0 для этой MID-секции; формула ниже не переносится
без изменения на слоистую/смещённую секцию с B≠0.

Основной выбранный индикатор:

\[
\eta_K^2=\int_K\left[
(N^*-N_h)^TA^{-1}(N^*-N_h)+
(M^*-M_h)^TD^{-1}(M^*-M_h)+
(Q^*-Q_h)^TS^{-1}(Q^*-Q_h)
\right]dA.
\]

η_K² имеет единицы **N·mm**. Без множителя 1/2 это аналог квадрата
энергетической нормы, то есть 2U ошибки в соответствующей модели.
Сохранять отдельно мембранную, изгибную и сдвиговую части; не вводить
произвольных настраиваемых весов и не нормировать почти нулевую N отдельно.
Глобальную диагностику η_rel=sqrt(sum η_K²/(2SENE_h)) выводить только при
SENE_h>0; она не является доказанной относительной ошибкой решения.

Для первого варианта q_h=(N_h,M_h,Q_h) задаётся **несглаженными элементными
центроидными** результантами, кусочно постоянными на K. Восстановленное q*
получается так:

1. В каждой вершине собрать патч центров соседних элементов. По площади
   взвешенным МНК аппроксимировать каждый компонент линейным полиномом
   c0+c1·ξ+c2·η в локально масштабированных координатах патча.
2. Расширять патч на соседнее кольцо до полного ранга и числа обусловленности
   ≤1e8. Если это не достигнуто, зарегистрировать отказ восстановления и
   остановить цикл; не заменять поле незаметно константой или нулями.
3. На границе использовать односторонний расширенный патч. На заделке не
   задавать искусственные M=0 или Q=0: там реакции и моменты неизвестны заранее.
4. Значения в вершинах интерполировать Q4-функциями на физической ячейке.
   Интегрировать разность **по площади**, а не только в центре: иначе часть
   линейной вариации восстановленного поля может быть пропущена.
5. Сравнить интегрирование 2×2 и 3×3; при изменении суммы индикатора более
   0.1% повысить порядок. При нулевом индикаторе и непрошедших целевых ошибках
   записать отказ/неинформативность индикатора, а не успех адаптации.

Это механически взвешенный индикатор восстановления **проекции** обобщённых
усилий. Центроидная аппроксимация отличается от интегрирования разности с
полным исходным полем FE в точках интегрирования. Она требует проверки на
линейных патчах и сеточной серии; не является гарантированной оценкой
дискретизационной ошибки. Одно лишь малое η не доказывает точность площадочных
напряжений или центрального прогиба.
Это также не точная дискретная энергетическая норма SHELL181 с его внутренними
несовместимыми модами и drilling-штрафом; указанная механическая метрика служит
обоснованным индикатором, который проверяется по целевым величинам.

Почему этот вариант: изгиб взвешен обратной жёсткостью порядка t³, мембрана
и сдвиг — своими жёсткостями порядка t. Восстанавливаются моменты и усилия,
а не градиент скалярной Poisson-функции. Для более строгих оценок нужны
статически допустимое восстановление и отдельное обоснование надёжности.
Для goal-oriented варианта потребовались бы дополнительные сопряжённые
задачи и производные семи функционалов; это следующий метод, не первый baseline.

## Как получить исходные поля в MAPDL

Документация SHELL181 v261 задаёт центроидные SMISC:
1–3: N11,N22,N12; 4–6: M11,M22,M12; 7–8: Q13,Q23.
Нужен новый native POST1/ETABLE-экспорт этих восьми **элементных** значений,
ID, связности, координат, площади, материала/секции и локального базиса.
Последовательности SMISC сверяются именно с используемой версией и элементом.

SMISC хранится в **элементных осях**; RSYS,0 не выполняет автоматическое
преобразование sequence-number ETABLE. На переходных Q4 ось e1 может не
совпадать с глобальной X или стороной IJ. Экспортировать/проверять фактический
базис; для стандартной плоской Q4 сверить первую параметрическую касательную
в центре с определением SHELL181. Поворот в общий XY:

\[
N_g=RN_eR^T,\qquad M_g=RM_eR^T,\qquad Q_g=RQ_e,
\]

где N и M здесь представлены симметричными матрицами 2×2, а столбцы R —
элементные базисные векторы в XY. Проверить инвариантность энергии при
повороте тестового элемента; простое применение RSYS,0 недостаточно.

В уже сохранённых fields.npz есть сглаженные узловые напряжения поверхностей.
Из них можно построить лишь диагностические приближения
N≈t(σ_top+σ_bottom)/2 и M≈t²(σ_top−σ_bottom)/12 для однородной линейной секции.
Это **не заменяет** несглаженные элементные данные и не даёт необходимого Q.
Полноценного индикатора из текущего компактного набора ещё не реализовано.

Экспортёр результантов, базисов и восстановления требуется написать.
Данные следующих разрешённых экспериментов получать через native MAPDL;
legacy RST-reader не исправлять и не использовать его непройденное чтение
как источник индикатора. В этом плане экспорт не выполняется.

## Маркировка и согласованная сетка Q4

Начальная общая сетка обоих методов: h=50 mm, 240 элементов, 1254 DoF.
Для локального метода сортировать η_K² по убыванию и выбирать минимальное
множество M с sum(K∈M)η_K² ≥0.5·sum(K)η_K². Равенства разрешать по ID;
параметр 0.5 фиксируется заранее. Сохранять отмеченную долю и **фактическое**
число изменённых элементов после переходных разбиений.

Первый кандидат построения — документированный native EREFINE:

```apdl
! Только в будущей разрешённой ненагруженной рабочей копии:
! Отмеченные ID предварительно сохранены в ELEM-компоненте marked_component.
ALLSEL,ALL
EREFINE,marked_component,,,1,0,OFF,ON
```

Поля: NE1, NE2, NINC, LEVEL, DEPTH, POST, RETAIN.
LEVEL=1, DEPTH=0; POST=OFF для detached mesh, RETAIN=ON для all-quad.
Сначала удалить прямые D/SFE с рабочей копии и исключить IC/CP/CE;
после уточнения заново наложить P1 по физическому контуру и давление по
проверенным нормалям. Материал, TYPE, SECNUM, толщина и ориентация должны
сохраниться и быть проверены; компоненты элементов/узлов обновить.
Оригинальную модель/reference не изменять.
После ESEL/маркировки восстановить ALLSEL,ALL, оставив компоненту отмеченных
ID: refinement ограничивается выбранными элементами, и соседние переходные
ячейки должны быть доступны. Выбор только отмеченных клеток не сохранять.

Документация допускает локальное уточнение area/detached meshes и изменение
соседних элементов в переходной области. Но RETAIN=ON сам по себе не
доказывает совместимость именно нашего SHELL181-варианта, отсутствие висячих
узлов или качество. До первого адаптивного solve обязателен отдельный
**mesh-only тест** с равномерной и локальной маркировкой, который ещё не проведён.

Приёмка каждой построенной сетки, одинаковая для обоих методов:

- Только четырёхузловые SHELL181 с четырьмя различными вершинами.
- Совпадение целых рёбер соседей; каждое внутреннее ребро разделяется ровно
  двумя элементами. Не должно быть вершины строго внутри чужого ребра без
  согласованного разбиения этого ребра, дублированных узлов или пересечений.
- Покрытие ровно прямоугольника, площадь 600000 mm², тот же контур, z=0,
  нормали +Z. Обязательны положительные Jacobian в углах и точках интегрирования.
- Предварительно фиксируем: aspect ratio≤4, углы 30°–150°,
  scaled Jacobian≥0.2; дополнительно native shape checks включены.
  Порог качества не ослаблять после получения неудобного результата.
- Точные P1 DOF восстановлены; давление даёт +3000 N. Число свободных DoF
  из топологии используется для прогноза и сверяется с Number of equations.

При провале — сохранить отказ и остановить метод, а не добавить CE для
висячих узлов, треугольники, отключить shape check или продолжить solve.
Резерв — отдельный генератор согласованных quad transition templates,
требующий реализации и тестов. Простое quadtree red-деление оставляет висячие
узлы; его не принимать за готовую согласованную локальную сетку. Глобальное
распространение разбиений учитывать как фактическую стоимость метода.

## Равные бюджеты DoF и честное измерение времени

Равномерный baseline: h=50,25,12.5,6.25,3.125 mm; фактические DoF P1:
1254, 5382, 22278, 90630, 365574. Исторические результаты — компараторы
точности, но старые отдельные времена solve не заменяют новый согласованный
хронометраж полных циклов.

Основные общие caps: 5382, 22278, 90630 DoF; 1254 — общий старт,
365574 — отдельная верхняя диагностическая граница с оговоркой self-reference.
Считать фактические DoF после всех переходных разбиений и закреплений,
а не число отмеченных элементов или 6N без вычитания ограничений.

Точное совпадение бюджетов предпочтительно. Пары с
abs(DoF_local−DoF_uniform)/DoF_uniform≤2% отдельно обозначать как близко
сопоставленные; публиковать саму разность. Если такое совпадение недостижимо,
сравнивать лучший достигнутый результат **под общим cap**, указывая фактический
DoF и заполнение бюджета DoF/cap. Это сравнение равных ограничений, а не
заявление о равных фактических DoF. Кривые ошибок строить по реальным DoF;
не экстраполировать и не приписывать интерполированным точкам выполненный solve.

До запуска очередного solve прогнозировать итоговые DoF новой сетки после
closure. Если шаг с фиксированной маркировкой превышает cap, завершить эту
бюджетную ветку на предыдущей допустимой сетке; не скрывать снижение θ для
попадания в красивый бюджет. Затраты на отклонённое построение тоже учитываются.

Для каждого метода и достигнутого уровня l:

\[
T^{cum}_l=T_{launch}+\sum_{k=0}^{l}
(T_{build,k}+T_{solve,k}+T_{export,k}+T_{quality,k}
+T_{indicator,k}+T_{mark,k}+T_{remesh,k}+T_{validation,k})
+T_{failed/rejected}+T_{close}.
\]

Не допускать двойного учёта участков. Дополнительно измерять сквозной wall
clock от запуска собственной сессии до её закрытия; расхождение с суммой
объяснять. Включать восстановление, повороты усилий, квадратуры, перестроение
сетки/нагрузки, проверки и неудачные попытки. Uniform также проходит все свои
предыдущие уровни; ему не приписывается только время последнего solve.
Для промежуточного достижения цели сохранять фактическую временную отметку
до этого события отдельно. Закрытие сессии добавлять только после его
выполнения к полному итогу соответствующей серии; неизвестную будущую стоимость
close не прибавлять задним числом к промежуточным измерениям.

Подготовку сохранённого reference показывать отдельной общей стоимостью,
а не включать лишь одному методу. Общее извлечение/оценку целей считать
одинаково для обоих. Разработку кода в основной wall-clock не включать;
одноразовую подготовку/импорт данных показывать отдельно. На будущих повторениях
чередовать порядок методов, использовать одинаковые solver/CPU/вывод и
сохранять все времена; не заявлять статистически надёжный выигрыш по одному
замеру. Число повторов и условия запуска зафиксировать до измерений.

Для основной и строгой цели **по отдельности** сравнивать минимум три результата:
семь ошибок при общем DoF-cap; минимальный фактический DoF до прохождения
всех семи проверок данной цели; полное накопленное время до того же события.
Сохранять случаи
«цель не достигнута при cap/временном лимите», не исключая их из отчёта.

## Что уже есть и что предстоит

| Возможность | Фактический статус |
|---|---|
| P1 linear, uniform Q4, native запуск/закрытие собственной сессии | Выполнено в предыдущем эксперименте |
| Сохранённые reference и метрики, физические круги, контроль баланса | Есть, с ограничениями аудита |
| Независимая квадратура кругов на structured grid | Реализована и проверена |
| Центроидные N/M/Q через SMISC, native EREFINE | Документированные средства MAPDL; наш адаптивный путь не проверен |
| Экспорт несглаженных усилий и локальных базисов | Требует реализации и проверки |
| Recovery в A/D/S-норме, патчи, маркировка | Требует реализации и тестов |
| EREFINE на этой direct-N/E SHELL181-модели, all-quad conformity | Требует mesh-only приёмки до solve |
| Поиск точки/квадратура кругов на переходных неструктурированных Q4 | Требует реализации и проверки |
| Бюджетный менеджер, cumulative timing и цикл сравнения | Требует реализации |
| Legacy RST-reader | Дополнительное чтение не прошло; исправление вне текущей задачи |
| ASMR++/обучение | В этом эксперименте не используются |

Последовательность после отдельного разрешения на исполнение: реализовать и
проверить экспорт/повороты/индикатор офлайн; затем mesh-only gate; затем
два первых будущих расчёта с проверкой переналожения P1/давления и качества;
после их приёмки — бюджетные серии. Тесты полиномиальных усилий, инвариантности
при повороте, постоянного поля, ранга граничных патчей и согласованности сетки
должны предшествовать интерпретации индикатора.

## Ограничение гладкой панели и ожидаемые материалы

На гладком прямоугольнике без отверстий, контактов и локальных нагрузок
индикатор может оказаться распределённым почти равномерно. Recovery и
переходные элементы могут съесть выигрыш по DoF и увеличить полное время.
Энергетический индикатор может уточнять заделку, хотя целевые круги и центральный
прогиб требуют другого распределения разрешения. Отсутствие преимущества
классической локальной адаптации — допустимый результат, а не повод менять
задачу или задним числом выбирать удачные метрики.

Новые runtime и бинарные файлы — только в новых приватных каталогах.
Для каждого цикла сохранять mesh/config hash, фактические DoF/качество,
η_N²/η_M²/η_Q², ранги патчей, marked IDs, дополнительное transition refinement,
статус, семь ошибок и все составляющие времени. В Git — выбранные компактные
CSV/JSON/графики с очищенным происхождением. Исторические run03/reference
и отрицательный RST-аудит не перезаписывать.
