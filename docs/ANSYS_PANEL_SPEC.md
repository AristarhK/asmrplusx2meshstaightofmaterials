# Стальная панель под давлением: постановка эксперимента

Дата постановки: 2026-11-16. Конфигурация: [panel.json](../experiments/ansys_panel/panel.json).
Переносимый запуск и расположение артефактов: [README эксперимента](../experiments/ansys_panel/README.md).

Это самостоятельно выбранный исследовательский пример участка стенки бака.
Он не является геометрией трансформаторного бака или утверждённым ТЗ ЭРСО.
Задача проверяет механическую постановку, автоматизацию MAPDL и сеточную
стабилизацию. ASMR++, inference и обучение в ней не используются.
Настоящая спецификация не подтверждает выполнение расчётов; фактические
запуски и их ограничения фиксируются отдельно в `ANSYS_PANEL_RESULTS.md`.

## Геометрия, единицы и материал

Полная прямоугольная срединная поверхность:

- `0 <= x <= 1000 mm`, `0 <= y <= 600 mm`, `z = 0`;
- постоянная толщина `t = 8 mm`, без сокращения по симметрии;
- единицы: N, mm, MPa = N/mm²; энергия — N mm;
- линейно-упругий изотропный материал S235JR: `E = 210000 MPa`, `nu = 0.30`.

`235 MPa` — диагностический предел текучести для обсуждения применимости
упругой модели. Это не нормативное допускаемое напряжение и не критерий
прочности реального бака. Пластичность не задаётся. Геометрия строится кодом;
нет отверстий, рёбер, швов, контактов, собственного веса и температуры.
Плотность для этой статической задачи не требуется.

## Элемент и неизменные настройки

Во всех сетках применяются четырёхузловые четырёхугольные оболочки SHELL181:

```apdl
ET,1,SHELL181
ETCONTROL,OFF
KEYOPT,1,1,0
KEYOPT,1,3,2
KEYOPT,1,8,2
SECTYPE,1,SHELL
SECDATA,8,1,0,5
SECOFFSET,MID
```

`KEYOPT(1)=0` включает мембранную и изгибную жёсткость, по шесть степеней
свободы на узел. `KEYOPT(3)=2` задаёт полное интегрирование 2×2 в плоскости
с несовместимыми модами. `KEYOPT(8)=2` сохраняет TOP, BOTTOM и MID.
Эти значения подтверждены [Element Reference, SHELL181, release 2026 R1](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_elem/Hlp_E_SHELL181.html).

Один слой материала 1, угол 0°, пять точек по толщине по правилу Симпсона;
узлы находятся на срединной поверхности. См. [SECDATA](https://ansyshelp.ansys.com/public/views/secured/corp/v261/en/ans_cmd/Hlp_C_SECDATA.html)
и [SECOFFSET](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_SECOFFSET.html).
`ETCONTROL,OFF` запрещает автоматическую смену технологии; см.
[ETCONTROL](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_ETCONTROL.html).

Остальные KEYOPT и коэффициент drilling stiffness сохраняются штатными.
SHELL181 связывает drilling-поворот с перемещениями штрафной жёсткостью.
Дополнительные физические закрепления ROTZ ради этой особенности не вводятся.
Энергия искусственной жёсткости AENE сохраняется отдельно от SENE;
предупреждения о pivots и механизмах требуют проверки, а не добавления
необоснованной заделки. При стандартном `KEYOPT(10)=0` нормальное по толщине
напряжение оболочки принимается нулевым в рамках плоского напряжённого состояния.

## Давление и знак нагрузки

`p = 0.005 N/mm² = 5 kPa`. Требуемая результирующая — `Fz = +3000 N`.
Узлы каждого элемента перечислены против часовой стрелки при взгляде со стороны
`+Z`: нижний левый, нижний правый, верхний правый, верхний левый.
Код проверяет векторное произведение рёбер каждого сгенерированного элемента:
поперечные компоненты нулевые, нормаль направлена в `+Z`.

Для этой проверенной ориентации положительное давление на нижнюю поверхность,
face 1, действует вдоль `+N`; face 2 даёт противоположное направление.
Команда `SFE,ALL,1,PRES,,0.005` выбрана по таблице нагрузок элемента, см.
[SHELL181, Surface Loads](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_elem/Hlp_E_SHELL181.html)
и [SFE](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_SFE.html).
Приёмка включает положительный прогиб, конечность полей и баланс реакций;
номер поверхности сам по себе не считается проверкой знака.

Для линейной модели моменты распределённой нагрузки относительно `(0,0,0)`:
`Mx = +900000 N mm`, `My = -1500000 N mm`, `Mz = 0`.

## Две постановки опирания

| Постановка | Граничные условия |
| --- | --- |
| P0, шарнирное опирание | UZ = 0 на четырёх кромках. UX = UY = 0 в `(0,0)`; UY = 0 в `(1000,0)`. Изгибные повороты на кромках свободны. |
| P1, заделка | UX, UY, UZ, ROTX, ROTY, ROTZ = 0 на четырёх внешних кромках. |

Начальная серия: линейная статика, `NLGEOM,OFF`, прямой sparse solver.
Закрепления P0 убирают три жёстких движения в плоскости; оставшиеся механизмы
контролируются диагностикой решателя, успешным решением и проверкой числа
уравнений. Число активных DoF читается из фактической строки sparse solver
`Number of equations`, отдельно сохраняется ожидаемое `6*Nnodes - Nconstraints`.
Произведение числа узлов на шесть не выдаётся за фактическое число уравнений.

После линейной серии P1 повторяется с `NLGEOM,ON` на самой подробной успешно
рассчитанной сетке. Материал остаётся упругим. Сравниваются линейный и нелинейный
P1 на одной сетке; различие более 2% по прогибам или контрольным напряжениям
требует пересмотра линейного приближения. Оболочечное давление при больших
поворотах обладает следящим эффектом. Формула `0.5*f^T*u` проверяет энергию
только линейного случая и не является проверкой внешней работы нелинейного P1.

## Сеточная последовательность

| Уровень CLI | h, mm | Деления x×y | Элементы | Узлы |
| --- | ---: | ---: | ---: | ---: |
| 0 | 50 | 20×12 | 240 | 273 |
| 1 | 25 | 40×24 | 960 | 1025 |
| 2 | 12.5 | 80×48 | 3840 | 3969 |
| 3 | 6.25 | 160×96 | 15360 | 15617 |
| 4 | 3.125 | 320×192 | 61440 | 61953 |

Сначала проверяются уровни 0–1 обеих постановок, затем последовательно
сгущаются обе серии до выполнения критериев либо уровня 4. Между сетками
не меняются геометрия, материал, секция, нагрузка, закрепления и настройки
элемента. Сгенерированные ячейки — плоские квадраты: отношение сторон 1,
углы 90°, коробление 0°, якобиан `h²/4`. Эти величины выводятся из координат
и связности; журнал команды `CHECK` сохраняется отдельно. Они не подменяют
диагностику решателя.

## Измерения и восстановление напряжений

Для каждого запуска сохраняются N элементов, N узлов, фактические DoF,
центральный UZ, максимальный модуль узлового UZ, реакции, моменты, SENE и AENE,
отдельные времена построения модели/сетки, solve и экспорта. Центральная точка
является узлом каждой заданной сетки. Реакции извлекаются для закреплённых DoF;
при суммировании моментов учитываются `r × R` и узловые реактивные моменты.
Узловые системы координат совпадают с глобальной системой панели.
`FSUM` не используется вместо реакций: он исключает силы от поверхностных
нагрузок; см. [FSUM](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_FSUM.html).

Напряжения извлекаются отдельно для TOP и BOT слоя 1, `RSYS,0`,
`/GRAPHICS,FULL`, `AVPRIN,0`. Экспортируются усреднённые узловые компоненты
`[sx,sy,sz,txy,tyz,txz]` в общей системе панели. Полный графический режим
устраняет одновременный вывод обеих поверхностей PowerGraphics; центральные
компоненты дополнительно выводятся через `PRNSOL,S,COMP,,ESOL`.
См. [SHELL](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_SHELL.html),
[PRNSOL](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_PRNSOL.html)
и [AVPRIN](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_cmd/Hlp_C_AVPRIN.html).

В [analysis.py](../experiments/ansys_panel/analysis.py) между узлами билинейно
интерполируется тензор напряжений. Напряжение Мизеса вычисляется после
интерполяции из шести компонентов, затем усредняется по площади. Средний
Мизес отличается от Мизеса среднего тензора. Сглаживание узловых напряжений
и последующая интерполяция — явные части определения метрики; это не
непосредственный максимум напряжений в интеграционных точках элемента.

Контрольные круги радиуса 8 mm неизменны во всех расчётах, центры:
`(500,300)`, `(500,48)`, `(48,300)` mm. Для каждой поверхности и круга вычисляются
средние sx, sy, txy и Мизес. Площадное интегрирование использует замену
`s = r²/R²`: Гаусс–Лежандр по s и периодические средние точки по углу.
Веса нормированы на площадь круга. Оба порядка удваиваются от 8×32 до
512×2048 точек; нужны два последовательных прохода допуска для всех четырёх
метрик: `abs(delta) <= 1e-9 MPa + 5e-4*scale`.
Для компонент `scale=max(abs(new),abs(old),0.001*max(VMnew,VMold))`,
для среднего Мизеса — `abs(VMnew)`. Квадратурная стабилизация не является
строгой оценкой ошибки интегрирования. Достижение предела без стабилизации
явно отмечается `quadrature_converged=false` и запрещает приёмку reference.

Отдельно сохраняются максимумы Мизеса в прямоугольнике
`24 <= x <= 976`, `24 <= y <= 576` mm и на всей панели. Метод проверяет
углы всех ячеек билинейного восстановленного поля, включая пересечения
границ внутреннего прямоугольника с ячейками. Для этого поля максимум
найден корректно: тензор внутри ячейки — выпуклая комбинация угловых значений,
а Мизес — выпуклая функция тензора. Это не оценка ошибки восстановления.
Глобальный максимум сохраняется как диагностика и не заменяет площадные метрики.

## Независимая проверка Навье для P0

```text
D = E*t^3 / (12*(1-nu^2))
w(x,y) = 16*p/(pi^6*D) * sum_{m,n positive odd}
  sin(m*pi*x/a)*sin(n*pi*y/b) /
  (m*n*((m/a)^2+(n/b)^2)^2)
```

Независимая функция реализована без обращения к MAPDL. Проверяются 4, 8, 16,
32, 64 и 128 положительных нечётных членов по каждому направлению; для ряда
нужны два последовательных изменения центрального прогиба не более `1e-7`
от последнего значения. Ориентир — около `0.570415 mm`.
Это решение теории Кирхгофа–Лява для P0, а не reference для P1 или точное
решение SHELL181 с поперечным сдвигом. Расхождение требует обсуждения теории,
сеточной стабилизации, закреплений и настроек элемента.

## Приёмка, reference и ограничения

Вертикальный баланс: `abs(sum(Rz)+3000)/3000 <= 0.001`.
Сохраняются также все компоненты сил и моментов и их невязки.
Успешный статус процесса отдельно не подтверждает правильность решения.

Численный reference для каждой постановки требует двух последовательных
переходов сгущения, на каждом одновременно:

- центральный и максимальный модуль прогиба изменились не более чем на 0.2%;
- SENE изменилась не более чем на 0.5%;
- средний Мизес каждого из трёх кругов обеих поверхностей изменился не более
  чем на 1%; квадратура обоих сравниваемых уровней стабилизировалась.

Знаменатель относительного изменения — абсолютное значение на подробной
сетке. Для компонент напряжений сохраняются абсолютная разность в MPa и
нормировка `max(abs(new),abs(old),0.001*max(VMnew,VMold))`; эти компоненты
остаются диагностикой и не вводят скрытых дополнительных критериев.
При нулевом знаменателе и ненулевой разности относительная ошибка не считается
конечной. Прошедшие переходы в начале серии не компенсируют неудачный последний
переход. Если критерии на уровне 4 не выполнены, reference не объявляется.

Стабилизация перечисленных величин не доказывает точность относительно
континуального решения. Сингулярности и особенности закреплений, восстановление
узловых напряжений, приближения оболочечной теории и ограниченная сеточная серия
остаются ограничениями. Проверка текучести не заменяет расчёт пластичности,
устойчивости или нормативную оценку бака.

## Изоляция расчётов и происхождение данных

Используется существующее окружение Python/PyMAPDL и собственная сессия
MAPDL: `nproc=2`, `additional_switches="-smp"`, gRPC. Исполняемый файл и
машинные каталоги передаются CLI/переменной окружения. Runtime каждого вызова
создаётся заново под LOCALAPPDATA; закрывается только созданная сессия в finally.
Найденные прежние проекты и завершённые результаты не изменяются.

Каждый выходной каталог новый. Manifest сохраняет конфигурацию и SHA-256,
исходники и их SHA-256, фактический Python, версии пакетов и путь solver.
Компактные измерения предназначены для Git; бинарные файлы MAPDL, полные
журналы, поля и локальные настройки остаются в runtime/`.local`.
Исторические ASMR++-артефакты сохраняются без изменений.
