# Предварительный протокол оптимизации координат

Исходный опубликованный mesh-only gate: `24bba5fd0e1c2cf7d9da25a77607b5c12fd7625b`.
Этот протокол фиксируется **до первой оптимизации трёх сохранённых сеток**.
Машинные параметры: [coordinate_protocol.json](../experiments/ansys_panel/meshing/coordinate_protocol.json).
Один алгоритм и одинаковые ограничения применяются ко всем трём случаям.

Используется уже установленный SciPy 1.17.1, SLSQP. Новых пакетов не требуется.
Для каждой сетки — ровно одна детерминированная попытка из исходных координат,
максимум 200 итераций, ftol=1e−9, шаг численного дифференцирования 1e−7
в нормированных переменных. Случайных начальных точек и скрытых рестартов нет.

Минимизируем τ при κ₂(J_K,p)≤τ для всех элементов K и восьми точек p
(четыре угла, четыре точки Гаусса). Это тот же показатель, что в gate.
Все соседние элементы перемещаемого узла участвуют в цели и ограничениях;
фиксированные элементы задают неизменную нижнюю границу для τ.

Переменные — XY внутренних узлов элементов с исходным κ>4 и двух колец
соседства по целым рёбрам. Остальные узлы фиксированы. Физические граничные
узлы остаются точно на исходных местах, z=0. Для сохранения разрешения
отмеченной области фиксируются также все вершины исходных refined-ячеек,
четыре вершины которых лежат в объединении отмеченных исходных base-Q4.
Связность, ID, число узлов/элементов, атрибуты и секция неизменны.

Для узла i размер h_i — минимальная длина его исходного инцидентного ребра.
Переменные нормируются на h_i, радиальное смещение ограничено 0.20h_i.
У каждой затронутой ячейки во всех восьми точках det J≥0.25 det J_original;
scaled Jacobian≥0.2, углы 30°–150°. Дополнительно отношение площади к исходной
лежит в [0.5,2], длины каждого ребра — в [0.7,1.3] исходной длины.
Пересечения, наложения, инверсия и вырождение недопустимы. Условные пробные
векторы оптимизатора не являются принятыми моделями; публикация успешного
варианта требует всех ограничений и полного прежнего независимого валидатора.

Проверка ограничений оптимизации: допуск 1e−7 в безразмерных величинах,
минимальное уменьшение глобального максимума κ — 1e−8. Критерии независимого
валидатора остаются прежними, включая aspect≤4, и не ослабляются допуском
оптимизатора. Остановка — штатное завершение SLSQP или 200 итераций.
Сохраняются статус, причина остановки, число итераций/вычислений и журнал.
Из одной траектории выбирается лучший допустимый улучшающий итерат, включая
конечный; это не повторная попытка. Он может быть принят и при нештатном
завершении оптимизатора, если все ограничения выполнены; success оптимизатора
и геометрическая приёмка указываются независимо.
При отказе результат сохраняется как отрицательный; другая попытка автоматически
не выполняется. Сходимость локального оптимизатора не доказывает глобальный минимум.

Сначала сохраняются локализация нарушений и изображения исходных переходов
с ID и качеством. Затем отдельно сохраняются координатные варианты и повторная
геометрическая проверка. Только прошедшие варианты поступают в новые MAPDL-модели
для native CHECK, проверки секции, атрибутов, переналожения P1/давления и +3000 N.
Результаты геометрической приёмки и устранения native warnings показываются
раздельно. Ожидаемые свободные DoF остаются топологическим прогнозом.

Новых solve, индикатора, обучения или исправления RST-reader нет. Основная
и строгая цели точности не оцениваются. Собственный генератор переходных сеток
не реализуется автоматически при отрицательном результате.
